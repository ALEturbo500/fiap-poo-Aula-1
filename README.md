🧠 Desafio de Reflexão
Pergunta: Por que precisamos criar uma classe Passageiro? Não seria mais fácil apenas criar variáveis soltas no main, como String nomeAna = "Ana" e double saldoAna = 50.0?
Pense: E se o FiapRide tiver 1 milhão de usuários? Como a Classe ajuda a resolver isso?

Resposta: A classe Passageiro ajuda a organizar os dados de cada usuário em um único lugar, como nome e saldo, sem precisar criar várias variáveis soltas no main. 
Isso facilita muito o desenvolvimento, porque se o FiapRide tiver 1 milhão de usuários, seria impossível criar variáveis manualmente para cada um. 
Com a classe, podemos criar vários passageiros de forma automática, organizada e muito mais prática.
